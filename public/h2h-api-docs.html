H2H API — Host to Host

Dokumentasi H2H API

Integrasikan sistem/toko kamu langsung ke katalog produk kami: produk marketplace biasa dan Topup Game, lengkap dengan skema input per produk. Order otomatis dipotong dari saldo akunmu — kalau saldo kurang, sistem otomatis membuatkan QRIS dan order akan lanjut diproses sendiri begitu QRIS-nya dibayar.

Base URL: https://austinstore.id/api/h2h/v1
Auth: header X-API-Key
Format: JSON

Autentikasi

Ambil API Key kamu dari halaman akun (menu H2H API setelah login) — satu key aktif per akun. Sertakan di header X-API-Key pada setiap request ke /api/h2h/v1/*. Semua order dipotong dari saldo akun pemilik key tersebut, jadi pastikan saldo cukup atau siap dibayar via QRIS otomatis.

curl
curl https://austinstore.id/api/h2h/v1/balance \
  -H "X-API-Key: h2h_live_xxxxxxxxxxxxxxxxxxxxxxxx"
API Key hanya ditampilkan sekali saat digenerate/regenerate. Kalau hilang, generate ulang dari halaman akun (key lama otomatis nonaktif).

Buat Order

Membuat order baru. Kirim ref_id milikmu sendiri supaya request bisa aman diulang (idempotent) — kalau ref_id yang sama dikirim lagi, API akan mengembalikan order yang sudah ada, bukan membuat order baru.

Body — produk general

FieldTipeKet.
product_typestringselalu "general"
product_variant_idstringdari endpoint Katalog
quantitynumberdefault 1, maks 50
ref_idstringopsional, id transaksi milikmu

Body — produk topup game

FieldTipeKet.
product_typestringselalu "topup"
category_keystringdari endpoint Katalog
service_codestringdari endpoint Item Topup Game
target_idstringUser ID / nomor tujuan
zone_idstringZone ID, hanya untuk game yang butuh (lihat input_fields)
ref_idstringopsional, id transaksi milikmu

Cek Status Order

Bisa dipanggil pakai id internal atau ref_id milikmu sendiri. Kalau statusnya masih awaiting_payment, endpoint ini otomatis mengecek ke penyedia QRIS dan langsung melanjutkan order kalau ternyata sudah dibayar — jadi aman dipakai untuk polling walau kamu tidak pasang webhook.

GET/order/:id
curl
curl https://austinstore.id/api/h2h/v1/order/TRX-INVOICE-0001 \
  -H "X-API-Key: h2h_live_xxxxxxxxxxxxxxxxxxxxxxxx"

Webhook

Kalau kamu atur webhook_url dari halaman akun (menu H2H API), kami akan mengirim POST ke URL tersebut setiap kali order selesai diproses (baik langsung lewat saldo maupun setelah QRIS dibayar). Tidak pasang webhook? Tidak masalah — cukup gunakan Cek Status Order secara berkala.

Payload

json
{
  "event": "order.success",
  "data": { "id": "a1b2...", "ref_id": "TRX-INVOICE-0001", "status": "success", "price": 20979, "result": { "...": "..." } },
  "sent_at": "2026-09-28T10:15:04.000Z"
}

Kemungkinan nilai event: order.success, order.failed.

Verifikasi Signature

Setiap request webhook disertai header X-H2H-Signature: HMAC-SHA256 dari raw body, ditandatangani pakai webhook_secret milikmu (ditampilkan sekali saat kamu set webhook URL).

javascript
const crypto = require("crypto");

function isValid(rawBody, signatureHeader, webhookSecret) {
  const expected = crypto.createHmac("sha256", webhookSecret)
    .update(rawBody)
    .digest("hex");
  return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(signatureHeader));
}
Gunakan raw body (string mentah sebelum di-parse JSON) untuk verifikasi, bukan hasil JSON.stringify() ulang — urutan key yang berubah akan bikin signature tidak cocok.

Harga Khusus H2H

Semua harga yang dikembalikan lewat H2H API (katalog, item topup, hasil order) sudah dihitung dengan diskon khusus H2H yang diatur owner toko — kamu tidak perlu menghitung ulang. Diskon ini otomatis dikreditkan kembali ke saldomu setelah order berhasil, jadi harga yang kamu lihat di respons API memang harga akhir yang kamu bayar.
