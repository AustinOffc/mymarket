Koneksi API VIP Reseller

Dapatkan API ID & API Key dari akun vip-reseller.co.id kamu. Key yang sudah tersimpan tidak ditampilkan lagi di sini — kosongkan field kalau tidak ingin menggantinya.

Margin Harga Jual

Harga jual ke buyer = harga dasar API + margin. Pilih persen (mis. 5%) atau nominal tetap (mis. Rp200 per item).

Kategori & Foto Topup Game

Klik kotak foto untuk atur gambar dari URL (gaya itemku/VIP Reseller). Kategori nonaktif tidak ditampilkan di dashboard & menu Topup Game.

Koneksi API H2H OkeConnect

Dapatkan Member ID, PIN & Password dari akun OkeConnect (h2h.okeconnect.com) kamu. PIN/Password yang sudah tersimpan tidak ditampilkan lagi — kosongkan field kalau tidak ingin menggantinya.

Margin Harga Jual

Harga jual ke buyer = harga modal + margin. Margin dibagi 2 tingkat berdasarkan harga modal produk — cocok kalau produk murah lebih pas pakai persen, sedangkan produk mahal lebih pas nominal tetap. Tidak ada kolom voucher diskon pada order PPOB.

Kategori PPOB

Nonaktifkan kategori yang belum siap dijual — kategori nonaktif otomatis disembunyikan dari halaman PPOB buyer.

Manajemen Produk PPOB
